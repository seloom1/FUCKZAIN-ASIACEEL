# FUCK ASIACEEL & ZAIN

تطبيق Android مبني على sing-box 1.10.7، ويدعم استيراد روابط **VLESS وVMess وTrojan** وملفات **WireGuard**. اسم الحزمة المثبتة: `com.fuckZAINASI`.

## نسخة محدثة

تم تجهيز فرع تحديث آمن لهذه النسخة مع رفع رقم الإصدار إلى `1.0.6` وتثبيت تعديلات توافقية للتجميع.

## الميزات

- إبقاء اتصال VPN بالخلفية مع زر إيقاف داخل إشعار الاتصال.
- إظهار عنوان IP العام واسم الدولة وعلمها بعد الاتصال؛ الاستعلام يُرسل عبر نفق VPN إلى `https://ipapi.co/json/` حتى يعرض عنوان الخروج الفعلي.
- توجيه استعلامات DNS عبر DNS مشفّر (TLS إلى `1.1.1.1`) داخل نفق الخادم؛ يُحلّ اسم خادم VPN نفسه عبر DNS الشبكة فقط لبدء الاتصال.
- خيار «تفعيل DNS القديم» يعيد سلوك الإصدار السابق عند التفعيل باستخدام DNS الشبكة المحلي؛ وعند إيقافه يبقى DNS عبر الخادم.
- خيار **Bypass LAN route (VPN)** يترك شبكات LAN الخاصة وlink-local على اتصال الشبكة المحلي؛ عند تفعيله يستخدم جدول مسارات IPv4 مجزأة.
- تعرض «إدارة الروابط» ملاحظة قابلة للضغط تفتح قناة Telegram `@freevpsiraq` للحصول على السيرفرات، مع التنبيه إلى تحديث الروابط يومياً.
- استثناء تطبيقات مختارة من VPN؛ تعرض الشاشة أسماء التطبيقات وأيقوناتها، وتحفظ الحزم المختارة، وتعيد الاتصالات عند تغيير الإعدادات.
- تظهر رسالة الواجهة: **تباً لسياسة الاستخدام العادل**.

## الخصوصية وصلاحية التطبيقات

يستعلم التطبيق من ipapi.co عن عنوان IP/الدولة عند كل اتصال ناجح؛ سيرى المزود عنوان IP الذي يصل منه الطلب (المفترض عبر VPN).

## البناء

- Android Gradle Plugin 8.5.2، Kotlin 1.9.24، Java 17.
- `compileSdk` و`targetSdk` 34، و`minSdk` 24.
- `app/libs/libbox.aar` يضم sing-box 1.10.7 ومكتبات Android لمعمارية `arm64-v8a` و`armeabi-v7a`.

بعد تثبيت Android SDK 34 وJava 17:

```bash
./gradlew assembleDebug assembleRelease
```

ملف Debug الموقّع بمفتاح التطوير: `app/build/outputs/apk/debug/app-debug.apk`. ملف Release الناتج غير موقّع ما لم يُضَف مفتاح توقيع رسمي.

## التحقق

تم تجميع نسختَي Debug وRelease من بناء نظيف وفُحص معرّف الحزمة وصلاحيات APK ومعماريات المكتبة وتوقيع Debug سابقاً. النسخة المحدثة في الفرع `fix/update-vpn-app` مرفوعة إلى `1.0.6`.
