# FUCK ASIACEEL & ZAIN

تطبيق Android مبني على sing-box 1.10.7، ويدعم استيراد روابط **VLESS وVMess وTrojan** وملفات **WireGuard**. اسم الحزمة المثبّتة: `com.fuckZAINASI`.

## الميزات

- إبقاء اتصال VPN بالخلفية مع زر إيقاف داخل إشعار الاتصال، وإعادة محاولة بدء النفق تلقائياً حتى ثلاث مرات عند فشل البدء.
- إظهار عنوان IP العام واسم الدولة وعلمها بعد الاتصال؛ الاستعلام يُرسل عبر نفق VPN إلى `https://ipapi.co/json/` حتى يعرض عنوان الخروج. قد لا تتوفر النتيجة عند انقطاع الخدمة أو بلوغ حد الاستخدام لدى مزود البيانات.
- استخدام DNS الشبكة المحلية افتراضياً لزيادة التوافق مع الشبكات التي تحجب DNS المشفّر؛ يمكن اختيار DNS المشفّر عبر النفق من الإعدادات، ويتطلب السماح بالوصول إلى `1.1.1.1:853`.
- خيار **Bypass LAN route (VPN)** يترك شبكات LAN الخاصة وlink-local على اتصال الشبكة المحلي؛ عند تفعيله يستخدم جدول مسارات IPv4 منفصلة بدلاً من مسار VPN افتراضي `0.0.0.0/0`، ويعيد الاتصال عند تغيير الإعداد أثناء تشغيل VPN.
- استيراد روابط VLESS وVMess وTrojan وWireGuard من الحافظة، بما في ذلك عدة روابط في السطر نفسه أو الاشتراك المشفر بـ Base64.
- إضافة اشتراك باسم ورابط HTTPS أو سيرفر من الحافظة عبر زر (+)، مع قائمة بطاقات قابلة للفتح؛ التحديث المباشر يستخدم Wi-Fi/بيانات الهاتف ولا يوقف الـVPN، ويحافظ على السيرفر المتصل به إن أزاله المزود أثناء التحديث.
- واجهة رئيسية صغيرة: اسم التطبيق وزر الاتصال، ثم السيرفر والبروتوكول والحماية، يليها IP والدولة والسرعتان في بطاقة موجزة. موجة النبض متحركة وتتغير مع مرور البيانات، وتُقاس السرعة كل نصف ثانية.
- تعرض «إدارة الروابط» ملاحظة قابلة للضغط تفتح قناة Telegram `@freevpsiraq` للحصول على السيرفرات، مع التنبيه إلى تحديث الخطوط يومياً.
- استثناء تطبيقات مختارة من VPN؛ تعرض الشاشة أسماء التطبيقات وأيقوناتها، وتحفظ الحزم المختارة، وتعيد الاتصال عند تغيير الاستثناءات أثناء تشغيل النفق.

## الخصوصية وصلاحية التطبيقات

يستعلم التطبيق من ipapi.co عن عنوان IP/الدولة عند كل اتصال ناجح؛ سيرى المزود عنوان IP الذي يصل منه الطلب (المفترض أن يكون عنوان خروج VPN). لعرض التطبيقات المثبتة على Android 11 وما بعده، يطلب التطبيق صلاحية `QUERY_ALL_PACKAGES`. هذه الصلاحية تخضع لسياسة Google Play وتتطلب تبريراً عند النشر في المتجر.

## البناء

- Android Gradle Plugin 8.5.2، Kotlin 1.9.24، Java 17.
- `compileSdk` و`targetSdk` 34، و`minSdk` 24.
- `app/libs/libbox.aar` يضم sing-box 1.10.7 ومكتبات Android لمعمارية `arm64-v8a` و`armeabi-v7a`.

بعد تثبيت Android SDK 34 وJava 17:

```bash
./gradlew assembleDebug assembleRelease
```

ملف Debug الموقّع بمفتاح التطوير: `app/build/outputs/apk/debug/app-debug.apk`. ملف Release الناتج غير موقّع ما لم يُضَف مفتاح توقيع الإصدار الخاص بالمالك.

تم تجميع نسختَي Debug وRelease من بناء نظيف وفُحص معرّف الحزمة وصلاحيات APK ومعماريات المكتبة وتوقيع Debug. يلزم هاتف Android فعلي وبيانات خادم صالحة لاختبار اتصال VPN وفتح المواقع عملياً.
